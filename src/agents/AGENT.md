# Agents - Documentación para IA

## Propósito
Esta carpeta contiene documentación y prompts diseñados para que agentes de IA comprendan las reglas, patrones y convenciones del proyecto.

## Estructura de un Agent File

### Nombre
`[nombre-del-agente]-agent.md`

### Contenido Sugerido
1. **Rol**: El rol que debe tomar el agente
2. **Responsabilidades**: Qué tareas debe realizar
3. **Reglas**: Restricciones y reglas a seguir
4. **Patrones**: Patrones de código a utilizar
5. **Ejemplos**: Código de ejemplo
6. **Prohibido**: Qué no debe hacer

## Agent: Code Review Agent
Revisa código para:
- Validar convenciones de nombres
- Verificar manejo de errores
- Detectar código duplicado
- Sugerir mejoras de performance

## Agent: Testing Agent
Ayuda a:
- Generar tests unitarios
- Verificar coverage
- Identificar edge cases
- Sugerir scenarios de prueba

## Agent: Documentation Agent
Responsable de:
- Mantener AGENT.md actualizados
- Generar JSDoc comments
- Crear CHANGELOG entries
- Documentar APIs
